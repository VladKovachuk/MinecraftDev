# Smoke Mod — описание проекта

## Назначение

**Smoke Mod** — мод для Minecraft Java Edition 1.20.1 на Fabric. Он добавляет полный цикл табака: получение семян, выращивание двухблочной культуры, сбор зелёных листьев, сушку на специальном столе и подготовленные табачные ингредиенты. Курительные предметы имеют анимацию, звук, дым, прочность, никотиновую систему и визуальные эффекты.

`Psychedelicraft-Legacy-1.7.10` используется только как донор идей и референс поведения. Разработка ведётся в `smokemod_main` под API Minecraft 1.20.1.

## Реализованные игровые системы

| Область | Текущее поведение |
|---|---|
| Курительные предметы | Обычная сигарета, сигарета с фильтром и джоинт. После первой затяжки NBT `lit` переключает модель на зажжённую. |
| Разница сигарет | Обычная сигарета добавляет эффект серости. `FilteredCigaretteItem` отключает серость, возвращая нулевые параметры эффекта. |
| Дым | Звук затяжки и выдоха, продолжительный выдох через `ExhalationManager`, кастомная частица `cigarette_cloud`. |
| Никотин | Серверный уровень 0–100, сохранение через `PersistentState`, убывание, урон при нуле, S2C-синхронизация и HUD лёгких. |
| Серость | Пост-эффект GLSL, плавное появление и исчезновение, серверное затухание, мгновенный сброс при смерти. |
| Табак | Семена сажаются только на пашню. Культура имеет возраст 0–4; на стадиях 3–4 состоит из двух блоков. |
| Получение семян | Семена выпадают из обычной и высокой травы с фактическим шансом 1,5%; зрелый табак генерируется группами в выбранных тёплых и умеренных биомах. |
| Сушильный стол | Соединяется с соседними столами multipart-моделью, открывает собственный GUI, хранит девять листьев, показывает их на поверхности и сушит независимо от погоды. |
| Обработка сырья | `green_tobacco_leaf` превращается в `dried_tobacco_leaf` на тех же девяти позициях. Добавлен предмет с ID `chopped_tobacco`, отображаемый как “Shredded Tobacco”. |

## Техническая база

- Minecraft 1.20.1, Fabric Loader, Fabric API, Java 17, Gradle/Fabric Loom.
- Серверная и общая логика: `src/main`.
- Клиентский рендер, GUI, HUD и шейдеры: `src/client`.
- Постоянной внешней базы данных нет; никотин хранится в данных мира через `PersistentState`.
