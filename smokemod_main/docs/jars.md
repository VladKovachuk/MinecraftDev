# Банки

- `smokemod:jar` — маленькая банка на 16 шишек.
- `smokemod:jar_large` — большая банка на 64 шишки.
- Обе банки в творческой вкладке и при размещении пустые. ПКМ по установленной банке открывает хранилище.
- Один слот принимает свежие или сушёные шишки. Разные виды не смешиваются в одном стеке.
- Обычный клик, ПКМ по слоту, Shift+клик, перетаскивание и цифровые клавиши соблюдают вместимость.
- Счётчик показывает количество / вместимость. При добавлении шишек модель становится наполненной, при извлечении последней — пустой. Промежуточных уровней заполнения модели нет.
- Содержимое сохраняется в мире. При разбивании отдельно выпадают пустая банка и её содержимое.

## Ресурсы

Относительно `src/main/resources/assets/smokemod/`:

- `models/block/jar_empty.json`, `jar_large_empty.json` — пустые модели.
- `models/block/jar_empty.bbmodel`, `jar_large_empty.bbmodel` — редактируемые исходники Blockbench.
- `textures/block/jar_empty.png`, `jar_large_empty.png` — атласы стекла и крышек, сохранённые из исходных моделей без изменения UV. Содержимое исходных банок было отдельной геометрией; оно исключено из пустых моделей вместе со ссылками на текстуры шишек.
- `textures/gui/container/jar.png` — новый фон интерфейса. Слоты и надписи рисует `JarScreen`, поэтому их координаты точно совпадают с интерактивными областями.

Повторный экспорт пустых моделей: `python tools/prepare_empty_jars.py`.

## Проверка

`gradlew.bat build runGametest`

Все четыре игровых теста прошли, включая три новых теста банок и существующий тест сушильного стола. Проверены лимиты, остатки предметов, разные пути ввода, недопустимые предметы, сохранение NBT, заполненный инвентарь, смена модели, компаратор и выпадение при разбивании. Обе пустые модели дополнительно просмотрены в Blockbench. Клиент запущен без ошибок загрузки новых ресурсов; ручная проверка открытого интерфейса в мире остаётся доступна пользователю.
